# Проверка демонстрационного каркаса

Проверено **6 октября 2026 года (UTC)**. Объект проверки — три demo-главы и текущие
компоненты издания. Реальные архивы в этой версии отсутствуют.

## Сборка и данные

Успешно выполнены:

```sh
python3 tools/build.py --validate
python3 tools/build.py
python3 tools/build.py --check
node --test tests/*.test.cjs
```

- Проверены три JSON-главы, локальные пути к вложениям и диапазоны выделения кода.
- Сформированы пять файлов: данные для браузера, оглавление чтения и три полные
  статические главы. Проверка повторной сборки не обнаружила расхождений.
- **24 автоматических теста прошли; ошибок, пропусков и отмен нет.**

Тесты включают независимые контрольные значения GF(16), известные кодовые слова
БЧХ, перебор всех 32 768 слов для проверки нулевых синдромов и делимости на
порождающий полином, а также минимальное расстояние всех 128 кодовых слов.
Дополнительно проверены формула приведённых затрат, границы входных параметров,
исследовательская функция, совпадение CSV с данными глав и точные диапазоны кода.

Для графиков проверены экспорт без округления исходных чисел, выбор фактической
точки, разная сетка абсцисс, пустые ряды, постоянные, отрицательные и малые значения,
а также читаемый шаг подписей осей.

## Проверка браузера

Использованы Playwright 1.62.1 и Chromium 153.0.8010.0 в Linux без графической оболочки.
Команда — `node tools/browser-smoke.cjs`, с путём к доступному Chromium через
`ALMANAC_CHROMIUM_EXECUTABLE`.

| Область | Фактическая проверка | Результат |
| --- | --- | --- |
| Автономность | `file://`, контекст браузера без сети; контроль внешних HTTP(S)-запросов | Внешних запросов нет |
| Главы и вкладки | 3 главы × 6 вкладок × 2 ширины: 1440 и 360 px | 36 сочетаний без горизонтального выхода страницы за экран |
| Оглавление | Поиск, отсутствие результатов, хронология и карточки | Пройдено |
| БЧХ | Ввод сообщения, ошибки ввода, биты, контрольные синдромы, пять необнаруженных изменений | Пройдено |
| ТЭО | Изменение параметров, сброс, итог расчёта, таблица, CSV и SVG | Пройдено |
| Исследовательская модель | Изменение усиления и сброс сценария | Пройдено |
| Галерея и код | Увеличение, соседний рисунок, Escape, выделение строк, копирование | Пройдено |
| Навигация | Мобильное меню, переход к разделу, неизвестная глава, ссылка пропуска к содержанию | Пройдено |
| Тема | Переключение в тёмную тему и график | Пройдено |
| Без JavaScript | Полная глава БЧХ в `read/`, текст, таблица и исходный код | Пройдено |
| HTTP | Размещение под `/Almanac/`: скрипты, стили, расчёт, рисунки | Ошибок HTTP и JavaScript не зафиксировано |

Отдельно компонент графиков проверен на ширине 320, 600 и 900 px в светлой и тёмной
темах. По снимкам экрана просмотрены оглавление, лаборатория ТЭО и мобильная
лаборатория БЧХ. Снимки для обсуждения сохранены в `docs/images/`.

Браузерный сценарий записывает подробный результат, снимки и примеры выгрузок
в `artifacts/`. Это воспроизводимые временные файлы, они не включаются в коммиты.

## Практические границы проверки

- GitHub Pages не развёрнут. Проверена HTTP-подпапка локального сервера;
  фактический адрес Pages проверяется при отдельной публикации.
- Firefox, Safari, реальные устройства с iOS/Android и Windows в этой среде
  не запускались. Мобильная проверка означает узкий viewport Chromium.
- Демонстрационные Pascal-файлы не компилировались. Проверены отображение кода,
  диапазоны строк и математическое ядро браузерного примера.
- Не проводилась сверка с историческими программами владельца: их ещё нет
  в проекте. Учебный пример не служит доказательством корректности будущего переноса.
- Автоматическая проверка фокуса и клавиатуры не заменяет полноценную проверку
  со скринридером. Внешний вид физической печати отдельно не проверялся.

После изменения вычислений, состава главы или взаимодействий этот отчёт нужно
обновить фактическими результатами соответствующих проверок.
