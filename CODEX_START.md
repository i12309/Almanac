# Задание агенту для первого архива

Используйте этот текст **после согласования макета**, когда агенту доступны репозиторий
и исходные материалы. Замените путь и название работы своими значениями.

---

Продолжи проект Almanac в этом репозитории. Нужно подготовить одну достоверную главу
по моим материалам, сохранив согласованный интерфейс и автономный запуск `index.html`.

**Архив находится:** `<локальный путь к распакованным материалам>`.

**Пилотная работа:** `<название или папка работы>`.

Сначала прочитай `AGENTS.md`, `README.md`, `docs/CONCEPT.md`,
`docs/CONTENT_GUIDE.md` и `docs/CODEX_SPEC.md`.

1. Составь инвентаризацию архива. Сохрани исходные файлы без изменения, установи
   кодировки, версии и связи между документом, программой и результатами.
2. Подготовь досье по `templates/source-dossier.md`: задача, метод, результаты,
   точные источники, известные пробелы. Выполни доступную работу и задай конкретные
   вопросы там, где архив не позволяет установить существенный факт.
3. На основе `templates/work.json.example` собери одну главу в текущей структуре.
   Отличай оригиналы, производные материалы, реконструкции и новые учебные примеры.
   Не придумывай даты, воспоминания, графики и научные результаты.
4. Если алгоритм достаточно восстановлен, подготовь отдельный браузерный эксперимент
   и сверь его с оригиналом или независимыми контрольными примерами. Опиши степень
   проверки и отличия. Если оснований недостаточно, сохрани содержательную главу
   без интерактивного расчёта.
5. Пересобери готовое издание, проверь числа, локальный запуск без сети, материалы,
   чтение без JavaScript и узкий экран. Обнови `docs/VERIFICATION.md`.
6. Подготовь отчёт по `templates/import-report.md`: что перенесено, на чём основано,
   что проверено и что осталось неустановленным.

Не начинай массовую переработку остальных работ до проверки пилотной главы.
Не включай Pages в рамках импорта. Не помещай личный входящий архив в публичную
часть репозитория. Изменения интерфейса выполняй только по согласованной задаче;
необходимые исправления существующих компонентов делай минимальными.
